GitHub · ตัวอย่างเล่ม PDF

เขียนวิทยานิพนธ์ มก.
ให้ AI จัดเล่มตามคู่มือ

ติดตั้งด้วยคำสั่งเดียว เขียนเนื้อหาเป็นไฟล์ข้อความธรรมดา (Markdown) แล้วสั่ง AI ว่า “สร้าง PDF” ได้เล่มที่จัดหน้า ระยะขอบ หัวข้อ สารบัญ และเอกสารอ้างอิงตาม คู่มือการพิมพ์วิทยานิพนธ์ สายวิทยาศาสตร์ ของบัณฑิตวิทยาลัย

  1. 1

    ติดตั้ง (ครั้งเดียว)

    เปิด PowerShell (กดปุ่ม Windows พิมพ์ PowerShell) วางคำสั่งนี้แล้วกด Enter

    irm https://raw.githubusercontent.com/punpiti/kuthesis/main/install.ps1 | iex

    เปิด Terminal วางคำสั่งนี้แล้วกด Enter

    curl -fsSL https://raw.githubusercontent.com/punpiti/kuthesis/main/install.sh | bash

    ครั้งแรกใช้เวลาประมาณ 5–15 นาที ระบบติดตั้งเฉพาะสิ่งที่ยังไม่มี และสร้างโฟลเดอร์ thesis (Windows: ใน Documents, macOS/Linux: ใน home) จากนั้นทดลองสร้าง PDF ให้ดูว่าใช้ได้

  2. 2

    เขียน thesis/thesis.md

    เปิดด้วยโปรแกรมแก้ข้อความใดก็ได้ (แนะนำ VS Code มีหน้าตัวอย่างให้ดู) ในไฟล์มีหัวข้อครบตามคู่มือและวิธีเขียนอยู่ด้านบน เช่น

    # คำนำ ผีเสื้อจัดเป็นแมลงในอันดับ Lepidoptera ... Toole (2002) กล่าวว่า ... (พิสุทธิ์, 2527) ![ภาพที่ 1 วงจรชีวิตของผีเสื้อ](figures/lifecycle.png)
  3. 3

    สั่ง AI ว่า “สร้าง PDF”

    cd "$([Environment]::GetFolderPath('MyDocuments'))\thesis"; claude
    cd ~/thesis && claude

    พิมพ์ สร้าง PDF จะได้ thesis/output/thesis.pdf พร้อมรายงานสิ่งที่ต้องแก้ (เช่น อ้างอิงที่ไม่อยู่ในรายการ) ซึ่งแสดงเป็นตัวแดงใน PDF — แก้ใน thesis.md แล้วสั่งใหม่ได้เรื่อย ๆ ครั้งแรก Claude Code จะให้เข้าสู่ระบบด้วยบัญชี Claude

เลือกได้สองทาง

ทางที่ 1 · Markdown + AI

เขียน thesis.md แบบข้อความธรรมดา ภาพไว้ใน figures/ อ้างอิงแบบ (ชื่อ, ปี) รายการเอกสารอ้างอิงพิมพ์ธรรมดาได้

AI จัดรูปแบบอย่างเดียว ไม่แก้ถ้อยคำ ของนิสิต

ทางที่ 2 · เขียน LaTeX เอง

แก้ thesis/latex/thesis.tex (เป็นตัวอย่างเล่มเต็มให้แก้ต่อ) แล้วสร้าง PDF ด้วย

cd thesis/latex latexmk thesis

ไม่ต้องใช้ AI · รายละเอียดคำสั่งอยู่ใน README

ตัวอย่างผลลัพธ์

ระยะขอบวัดถึงฐานตัวอักษรตามคู่มือ (บน 1.5 นิ้ว ล่าง 1 นิ้ว เลขหน้าห่างขอบบน 1 นิ้ว) และตรวจเทียบกับตัวอย่างในภาคผนวกของคู่มือแล้ว · เปิด PDF ตัวอย่าง

สิ่งที่ติดตั้ง

โปรแกรมใช้ทำอะไร
TinyTeX + แพ็กเกจ LaTeXสร้าง PDF (ติดตั้งเฉพาะผู้ใช้ ข้ามถ้ามี TeX อยู่แล้ว)
ฟอนต์ TH Sarabun Newเก็บไว้ในโฟลเดอร์ thesis/kuthesis/fonts ไม่ต้องติดตั้งเข้าระบบ · ตรวจ checksum ก่อนใช้
Claude CodeAI สำหรับทางที่ 1 (ข้ามถ้ามี Claude Code, Codex หรือ Gemini CLI อยู่แล้ว · Windows ติดตั้ง Git ให้ด้วยเพราะ Claude Code ต้องใช้)
kuthesisclass, ตรามหาวิทยาลัย, คำสั่งสำหรับ AI — รันคำสั่งติดตั้งซ้ำเพื่ออัปเดต ไฟล์ที่เขียนไว้ไม่ถูกแตะ

คำถามที่พบบ่อย

ทำไมไม่ใช้ฟอนต์ตามคู่มือ

ฟอนต์ที่คู่มือกำหนด (AngsanaUPC, BrowalliaUPC, CordiaUPC ฯลฯ และ Times New Roman) เป็นฟอนต์มีลิขสิทธิ์ kuthesis ใช้ฟอนต์ฟรีที่ถูกกฎหมายแทน: TH Sarabun New (ฟอนต์แห่งชาติ) สำหรับภาษาไทย และ TeX Gyre Termes ซึ่งขนาดและความกว้างเท่า Times New Roman สำหรับภาษาอังกฤษ

ต้องเสียเงินไหม

kuthesis และโปรแกรมทั้งหมดฟรี ยกเว้น AI: Claude Code ต้องใช้บัญชี Claude (มีแบบเสียค่าบริการ) ถ้ามี Codex หรือ Gemini CLI อยู่แล้วก็ใช้แทนได้ หรือเลือกทางที่ 2 ซึ่งไม่ใช้ AI เลย

ข้อมูลวิทยานิพนธ์ถูกส่งไปที่ไหน

ไฟล์ทั้งหมดอยู่ในเครื่อง แต่เมื่อใช้ AI เนื้อหาที่ AI อ่านจะถูกส่งไปประมวลผลที่ผู้ให้บริการ AI ตามนโยบายข้อมูลของบริการนั้น ถ้างานยังเป็นความลับให้ปรึกษาอาจารย์ที่ปรึกษาก่อน หรือใช้ทางที่ 2

ใช้แทนแบบฟอร์มทางการได้ไหม

kuthesis ไม่ใช่เอกสารทางการของมหาวิทยาลัย ใบรับรองวิทยานิพนธ์และบทคัดย่อจัดตามตัวอย่างในคู่มือ บัณฑิตวิทยาลัยอาจกำหนดให้ใช้แบบฟอร์มทางการ โปรดตรวจข้อกำหนดล่าสุดก่อนส่งเล่ม
